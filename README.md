# OME legal pages

Privacy policy, terms of use and account deletion pages for the OME app, served with GitHub Pages.
Generated from `legal/` in the app repository with `node legal/build.mjs`; edit the Markdown there, not these files.

`admin/` is the admin panel. It is written by hand (not generated) and reads everything through the
admin-only database functions in the app repository (`supabase/migrations/20261101230000_admin_panel.sql`).
